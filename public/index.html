Squat Spotter

Check a package name for similarity to a small seed list of popular npm packages. The assessment can inform central policy; an organisation decides whether to block a package, for example through Cloudsmith.

The local backend requests npm metadata and download counts. This prototype does not run or install packages.

Use the API
Use curl against the running local server:
curl --get 'http://127.0.0.1:3000/v1/check' \
  --data-urlencode 'name=raect' \
  --data-urlencode 'ecosystem=npm'


Limits: The score is a heuristic, not a probability or a safety verdict. The seed corpus has limited coverage and cannot check every npm package. Similar names and low adoption can be legitimate. Slopsquatting is not assessed. Source on GitHub · Third-party notices.
